HOW TO USE ON ANDROID WITH ACODE
1. Download and extract purity_portfolio.zip.
2. In Acode, open the extracted purity_portfolio folder.
3. Open index.html to preview the website.
4. When publishing with GitHub Pages, upload index.html, style.css and script.js to the repository's root folder.
5. Keep all three files together.

CONTACT FORM
The Contact Me form prepares an email addressed to cheruspurity00@gmail.com using the visitor's email app. It does not send automatically. The visitor must review and press Send. A static GitHub Pages website cannot send email silently without a separate email service or backend.
